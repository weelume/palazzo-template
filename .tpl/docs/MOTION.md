# Palazzo 动效参考清单

采集日期为 2026 年 11 月 4 日。依据参考站的实际首页观察，以及公开页面 HTML 引用的组件源文件静态阅读记录。阅读过程中未执行第三方源码。本清单描述原站参数，模板自身的三端运行验收需另行记录。

公共缓动为 `cubic-bezier(.16,1,.3,1)`。原站响应式页面断点为 1200px 和 810px，转桌组件内部按自身宽度 1000px、礼卡编辑器按自身宽度 820px 切换布局。

## 首页餐桌

参考组件位于 `Y-b9XGsf4lfpOAYazIV1WSgzeCJZUBhI-c4mWwG_1RQ.BkvnPnSS.mjs` 的转桌组件。

| 项目 | 原站行为与参数 |
| --- | --- |
| 初始菜品 | 默认第 4 道，8 道菜以 45° 等分 |
| 自动切换 | 4.8 秒轮换，用户操作后等待 7 秒。仅组件在视口内、没有拖拽或吸附过程时自动轮换。250ms 轮询 |
| 入场 | 亚麻背景 opacity 0→1，1.2 秒。桌子桌面从 x 22%、rotate -35°、opacity 0 入场，小屏改为 y 16%。延迟 .2 秒、时长 2.4 秒 |
| 菜盘入场 | 每盘 scale 1.12、opacity 0→1，延迟 `.6 + index × .12` 秒、时长 1.1 秒。图片裁切放大 1.08 |
| 当前菜盘 | 距当前角度越近越大，中心最高 scale 1.26 |
| 文案切换 | 当前菜品随转桌角度取最近的 45° 档位。切换时长 .9 秒，减少动态效果时 .3 秒 |
| 指针拖拽 | 以真实桌心为基准计算 atan2 角差。拖拽距离超过 6px 才判为移动，单击切下一道。速度取前值 .6 加本帧 .4，释放限制在 ±900°/秒 |
| 惯性与回弹 | coast 时速度乘 `.93^(dt×60)`。速度绝对值小于 25°/秒后切吸附，目标为最近 45°。弹簧加速度为 `-120 × 角度差 - 18 × 速度`。角度差小于 .05° 且速度小于 .5°/秒时结束 |
| 键盘与滚轮 | 左右键切换，420ms 防连续触发。横向滚轮明显大于纵向或按 Shift 滚轮时切换。普通纵向滚轮保留页面滚动 |
| 小屏触摸 | 保留 `touch-action: pan-y`。桌子移至首屏下部，文字顶部排列 |
| 减少动态效果 | 关闭自动转动，取消入场运动，交互直接吸附 |

设组件宽高为 w / h。桌面桌径为 `1.4h`、菜盘环半径为 `.4656h`、盘径为 `.3064h`。桌心为 `max(w - .1745h, 660 + 环半径 + .65 × 盘径)`、`.54h`，正面角为 180°。

小屏以 `e=min(w,.5h)` 计算。桌径 `1.96e`、环半径 `.646e`、盘径 `.4257e`。桌心为 `w/2`、`h-.133e`，正面角为 270°。

## 首页内容与配酒

- 大标题按行进入。原站 DOM 可将文字拆成字符节点，但定时配置的 tokenization 为 line。起始 blur 8px、opacity .001、y 32px，1.2 秒恢复，内部延迟 .05 秒，各行 startDelay 依次 0 / .15 / .3 秒。
- 句中番茄盘先以 scale .6、rotate -12°、opacity 0 进入，spring bounce .2、延迟 .4 秒、时长 1.4 秒。随后 40 秒匀速转 360° 循环，离屏暂停。
- 首页菜单行在支持精确指针和悬停的设备上显示跟随鼠标的圆形菜盘。盘径 260px，跟随使用 spring stiffness 90 / damping 20。进入时 scale .6 / rotate -20° → scale 1 / rotate -8°，.9 秒。其他菜单行在 .5 秒内降至 opacity .5，离开后恢复。触屏不显示跟随层。
- 配酒状态为 wine / soft / none。开关联动菜单价格与首页套餐信息。价格由 145 加 wine 95 或 soft 65 组成，数值滚动 .8 秒，同公共缓动，数字使用 tabular-nums。减少动态效果时直接更新数值。
- 功能按钮背景和文字过渡 .4–.5 秒，悬停为低对比浅色背景。按压、焦点与禁用状态需分别保留。

## 擦玻璃

参考组件为 `FoggedWindow.Bea_zAmC.mjs`。

- 底层为真实餐厅夜景图，Canvas 雾层由缩小图重新放大、冷灰 tint、轻噪点组成。不是对整张图片切换一次透明度。
- 雾色为 `rgba(209,219,232,.26)`，强度 1。擦除笔刷桌面 96px，小于 700px 为 64px，边缘为径向渐变。
- 指针路径进行插值，补足连续笔触。原站在窗口监听 pointermove，只在组件范围内处理。组件触控策略保留 pan-y。
- 擦痕逐渐重新起雾，regrow 为 8 秒，合成衰减系数为 `dt / 8 × 1.4`。擦动随机生成小水滴，最大 60 颗，水滴受到向下加速度 40px/s²，寿命 2–5 秒。
- 雾上手写字为 Come in，宽度 54%，纵向位置 30%。小屏宽度为 `min(92%,54%×1.6)`。进入延迟 .7 秒，2.6 秒描写，30 秒后淡化，9 秒无操作后重新描写。
- Canvas 就绪后以 1.2 秒 ease-out 显现。设备像素比最高取 1.5。组件离屏停止持续绘制，减少动态效果时保留静态可读夜景。

## 菜单页

参考组件为 `SWfs0-aI45-1ac7ZaoChBtI4O9ZtdxMpTSkjIzQV2xA.1KRzJF9c.mjs`。

- 八道菜位于横向滚动轨道。鼠标按下后根据 clientX 差值同步 scrollLeft，累计移动超过 6px 后阻止误点。
- 释放后速度每帧乘 .95，按 `scrollLeft -= velocity × 16` 持续惯性，绝对速度低于 .02 时停止。触控使用原生横向滚动。
- 每个菜盘旋转角为轨道 `scrollLeft × .12`，经 spring stiffness 60 / damping 20 平滑。图片 zoom 1.08。
- 每张菜单卡片 y24 / opacity0 入场，1 秒，按 index × .1 秒错峰。标题沿用按行 blur8 / y32 的 1.2 秒入场。
- wine 与无酒精配饮互斥，套餐总价 .8 秒数值过渡。锚点导航分别到菜品、配饮、过敏原与杯卖酒。

## 餐厅与私人宴请

- 首屏照片 scale1.12→1，2.4 秒。标题延迟 .3 秒按行 blur8 / y32 入场，说明延迟 .8 秒，y12 / opacity0，时长1.2秒。
- 餐厅故事、年份时间线、供应商与图库各有独立视口触发。时间线、图库的静态截图不能证明滚动过程与悬停完成。
- 私人宴请座位图在 One table、Two tables、Standing 三个状态间切换。spring bounce .2、时长 .4 秒。状态分别对应 14、8+6、24 人，桌椅位置、数量、状态标题一起改变。
- 询问表单具备初始、提交中、成功、错误状态。模板演示应本地校验后明确显示未发送，保留原有布局与交互反馈。

## 礼卡

参考组件为 `TiltCard.D6pQEIfl.mjs` 和 `YpkxjzdSneH0PpkScIJulZAhR5_GMm5NJFfF5hYfOHg.6XSngg6e.mjs`。

- 首页礼卡根据鼠标位置沿 X/Y 轴倾斜，最大 ±10°。spring stiffness120 / damping18，移出回中心，透视900px，静止旋转6°。反光带横向位置 -30%→130%，透明度随离中心距离变化。
- 礼卡页顶部三张卡片扇形角度为 -18°、-8°、6°，容器随鼠标倾斜。触屏与减少动态效果时关闭指针倾斜。
- 编辑器在胡桃木、亚麻、夜色设计间切换。每次 rotateY 累加180°，正反面交替更新，1秒。预览固定 rotate -6°，额外沿指针 ±10° 倾斜，透视1000px，spring120 / 18。
- 礼卡金额默认480，可选100 / 250 / 480 / 自定义，最低20。邮寄附加6。金额变化 blur6→0，.3秒。
- 预览文案按金额变化。480及以上为双人配酒品鉴，250及以上为单人配酒，145及以上为单人品鉴，其他为晚餐金额。
- 宽度低于820px时改纵向布局并取消 sticky，桌面预览 sticky top120。设计切换、金额、配送、收赠人和寄语需联动预览。
- FAQ 展开/收起为 .7秒，同公共缓动。需保留键盘操作与独立 aria-expanded。

## 预约与导航

- 预约人数、日期与时间为可选按钮。日期改变后时间列表使用 AnimatePresence，x16 / opacity0 入场、x-10 / opacity0退场，.6秒。减少动态效果时只改变透明度。
- 选中背景/文字 .4秒过渡，满额时间禁用并划线。六人以上切换至私人宴请联系语义。动态日期以实际日期生成，不能固化采集当天日期。
- 原站小屏导航使用单独菜单布局，包含完整页面及预约入口。需要核对打开、关闭、背景滚动恢复与站内跳转。
- 法律页面及 read-me 主要使用标题入场与页面过渡。未在源码中发现动态视频，素材清单也未发现 video 文件。
