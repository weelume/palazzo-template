# 验证方法

在独立 Linux 目录冻结安装，运行 `pnpm typecheck`、`pnpm lint`、`pnpm build`。生产服务启动后检查十一页的中文和英文共 22 个路径，再停止验收服务。

浏览器按 1440×1000、834×1180、390×844 和 320px 窄屏检查布局、横向溢出、图片、控制台、中英文切换、菜单与背景滚动恢复。展示图覆盖首页、菜单、私人宴请和预约，截图尺寸以解码后实际像素记录。

逐项触发转桌自动轮换、暂停、键盘、拖拽惯性、配酒联动、40 秒旋转盘、菜单横拖与旋转、擦雾与恢复、水滴、座位布局、礼卡翻面与金额、FAQ 及预约选项。减少动态效果与真实触屏行为单独记录，不以桌面缩小视口视为真实触屏验证。

`.tpl/reports/verification.json` 记录实际检查命令、环境、结果、源码摘要和限制。`screenshots.json` 记录 CSS 视口、内容宽度、实际截图尺寸与图片错误。未覆盖项必须如实保留。
