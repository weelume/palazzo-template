## 字体

- MiSans 使用真实 400 / 700 字重的 Unicode 分片。`fonts/misans/MiSans-Regular.css` 和 `MiSans-Bold.css` 采用局部字体别名 `PalazzoMi`。二进制来自 `misans@4.1.0`，许可来源保存在 `fonts/misans/LICENSE-SOURCE.md`。MiSans 适用小米字体许可，分发前应按该许可核实使用方式。官方入口为 https://hyperos.mi.com/font/ 。
- Poppins 使用 400 / 600 / 700 的本地 WOFF2。许可为 SIL Open Font License 1.1，原文保存在 `fonts/Poppins-OFL.txt`。上游为 https://github.com/google/fonts/tree/main/ofl/poppins 。
- 原站英文展示字体为 Instrument Serif。真实 400 正体与斜体保存为 `fonts/instrument-serif-regular.woff2` 和 `fonts/instrument-serif-italic.woff2`。原站实际使用的 Google Fonts URL 及摘要已记录在 `sources.json`，SIL OFL 原文保存为 `fonts/InstrumentSerif-OFL.txt`。上游为 https://github.com/google/fonts/tree/main/ofl/instrumentserif 。
